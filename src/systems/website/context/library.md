Website began as Design Studio's Marketing starter and was renamed and rebuilt from itspatmorgan.com on 2026-11-01.

## Included

- **Theme:** colors, radius, and motion tokens copied from the site's `src/styles/global.css`, in light and dark. Type sizes, spacing, and widths are Tailwind's defaults, limited to the steps the site and its labs use.
- **Fonts:** Geist and Geist Mono as packages; Geist Pixel Square as `assets/fonts/GeistPixel-Square.woff2`.
- **Images:** the `debut` card textures, used by the `.texture-bg` class.
- **Button:** the site's shadcn base-nova button (`src/components/ui/button.tsx`).
- **Site shell:** `PageLayout.astro` with the Sidebar, Header, MobileNav, PageHeader, and Footer, rewritten in React. Links render through a `renderLink` prop so prototypes can navigate between their own pages; the theme toggle flips the theme boundary rather than `<html>`.
- **Lab page:** the frame from `src/layouts/LabLayout.astro`, without the site sidebar and footer.
- **Pixel wave text:** `src/components/PixelWaveText.astro` and `src/scripts/pixel-wave.ts`, rewritten in React; the helpers return cleanup functions.
- **Logo:** the four-pixel mark and its hover interactions (`src/components/layout/Logo.astro`, rewritten in React).
- **Shared site pieces:** Badge, Print photo, Project card (with each case study's live visual), Lab card (with live previews), Article list item, Kind words, Section header, and Media row, extracted from the site's pages and components.
- **Generative art:** the Pattern Engine's deterministic generators, `LiveEditorialVisual`, `GenerativePatternSurface`, `ArtCanvas`, and `UAMark` (`src/lab/editorial-art/`). Pattern Engine, the Lab prototype, keeps only its editor UI.
- **Theme hooks:** `useDark`, `useReduced`, and `usePhone` (`src/lib/hooks.ts`).
- **Case study scenes and demos:** the scene player and stages (`case-study`), and the Sublime, query builder, expansion, Design Studio, and Studio case demos, each folder with its stylesheet in `styles/site/`. `CaseStudyPage` and `Slide` port `CaseStudyLayout.astro` and `Slide.astro`.
- **Design Studio landing styles:** `styles/site/ds-landing.css`, from the `<style>` block of `src/pages/design-studio.astro`.
- **Tabs and Tooltip:** kept from the Marketing starter and restyled by the new tokens. The site has no equivalent yet.
- **Prose:** the site's `.prose` rules, rewritten as plain CSS under the theme class and renamed `.site-prose`, because Studio's Tailwind setup generates @tailwindcss/typography styles for any system using the class name `prose`.
- **Libraries:** Hugeicons (`libraries/icons`), Motion (`libraries/motion`), and html-to-image (`libraries/html-to-image`). IBM Plex Mono and Comic Neue are package fonts for the expansion and Studio case demos.

## Adaptations

- The site toggles dark mode with `.dark` on `<html>`; Studio uses `[data-color-mode="dark"]` on the theme boundary.
- The site's `@theme inline` color aliases are generated by Studio from the semantic names, so components use `var(--secondary)` rather than `var(--color-secondary)` in custom CSS.
- Logo styles live in `styles/theme.css` under the theme class, and its keyframes are prefixed `website-theme-`.
- The site's button drops its `dark:` overrides here, because Studio's dark tokens already supply those values.

- The site's global component stylesheets became files under `styles/site/`, imported by `styles/theme.css` and scoped to `.website-theme`. Sibling selectors (`a + b`) are wrapped as `:is(a + b)`, which selects the same elements, because Studio's scope check accepts only descendant and child combinators after the theme class.
- Internal component files start with `_`, so the Systems pages list one documented entry per folder; each folder's `index.ts` is its public surface.
- `useDark` follows the theme boundary's `data-color-mode`, not `.dark` on `<html>`. The generative art and Lab previews use it.
- `ArtCanvas` imports its paper textures from `assets/images/` instead of the site's `/images/textures/` URLs.
- Hand repairs after porting: `query-builder/source-glyphs.json` is copied beside `_NativeUI.tsx`; an unused parameter in `_QuerySearchBlank.tsx` and an unused import in `_OpenStudio.tsx` were removed for Studio's stricter TypeScript; `StudioQuote`, `StudioPress`, and `StudioLesson` were rewritten from Astro to React, with their styles appended to `styles/site/studio-case.css`.

The shadcn MIT notice is retained in `LICENSE`.
